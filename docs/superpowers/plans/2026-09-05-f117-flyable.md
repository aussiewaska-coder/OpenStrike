# F-117 Nighthawk Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the imported F-117 a selectable, flyable jet with a cockpit view and its own aerodynamics, without changing how the F-22 flies.

**Architecture:** `aero_model.gd`'s twenty baked-in `const` coefficients move into an `Airframe` profile, and `AeroModel` becomes instantiable from one. The formulas do not change -- they are generic aerodynamics; only the coefficients are aircraft-specific. `main.gd` gains a jet index so the aircraft control cycles Raptor, Nighthawk, Apache.

**Tech Stack:** Godot 4.7.2, GDScript, GL Compatibility renderer, Android export.

**Spec:** `docs/superpowers/specs/2026-09-05-f117-flyable-design.md`

```gdscript
extends RefCounted

## One aircraft's numbers, in one place.
##
## These were constants in aero_model.gd, which is where the reasoning for each
## of them still lives. They moved here so a second aircraft can hold different
## ones; the formulas that consume them did not change.

class_name Airframe

var display_name := "F-22 RAPTOR"

# Lift curve
var cl_slope := 4.6
var stall_alpha_degrees := 32.0
var cl_decay_degrees := 45.0
var post_stall_alpha_degrees := 55.0

# Drag polar
var cd0 := 0.067962
var k_induced := 0.055
var cd_wave := 0.076438
var drag_divergence_mps := 180.0
var cd_stalled := 1.10
var cd_stall_full_degrees := 70.0

# Airframe
var aero_authority := 0.00190657
var side_force_coefficient := 0.75
var load_limit_g := 9.0

# Thrust, as a multiple of gravity
var thrust_military_g := 0.55
var thrust_afterburner_g := 1.10
var thrust_idle_g := 0.05

# Control
var control_authority_floor := 0.10
var thrust_vector_authority := 0.38


## Peak lift coefficient, at the stall angle.
func cl_max() -> float:
	return cl_slope * deg_to_rad(stall_alpha_degrees)


## Where the wing's lift limit and the load limit cross. Derived, not chosen.
func corner_speed_mps() -> float:
	return sqrt(load_limit_g * 9.80665 / (aero_authority * cl_max()))


static func raptor() -> Airframe:
	return Airframe.new()
```

### Task 6: Orient and scale the model

**Files:**

- Modify: `scripts/jet/jet_controller.gd` (`_find_visual`, `_scale_to_reference`)

**Interfaces:**
- Consumes: `Airframe`.
- Produces: `Airframe` gains `scene_path: String`, `model_basis: Basis`, `reference_wingspan_m: float`, `hull_clearance_m: float`. `JetController._scale_to_reference()` applies `model_basis` before measuring.

**Why this task exists:** `_scale_to_reference()` reads `bounds.size.z` as the wingspan. The Raptor imports X-long with its span on Z, so that works. The F-117 imports 10.43 x 16.00 x 2.92 — Y-long and Z-thin — so the same code would read 2.92 m as the wingspan and scale the aircraft about five times too large.

- [ ] **Step 1: Write the failing test**

```gdscript
extends SceneTree

## Both aircraft must present the same way round once rigged: length on X, span
## on Z, up on Y, nose the same direction. The Raptor's basis is identity and
## defines the convention.

const AIRFRAME := preload("res://scripts/jet/airframe.gd")

func _init(): call_deferred("_run")

func _run():
	for profile in [AIRFRAME.raptor(), AIRFRAME.nighthawk()]:
		var scene = load(profile.scene_path)
		assert(scene != null, "%s scene must load: %s" % [profile.display_name, profile.scene_path])
		var model: Node3D = scene.instantiate()
		root.add_child(model)
		model.transform.basis = profile.model_basis
		await process_frame
		var bounds := _bounds(model)
		assert(bounds.size.x > bounds.size.z, "%s must be longer than its span" % profile.display_name)
		assert(bounds.size.z > bounds.size.y, "%s span must exceed its height" % profile.display_name)
		var factor: float = profile.reference_wingspan_m / bounds.size.z
		var span: float = bounds.size.z * factor
		assert(is_equal_approx(span, profile.reference_wingspan_m),
			"%s must scale to its real span" % profile.display_name)
		model.queue_free()
		await process_frame
	print("AIRFRAME_RIGGING_TEST_PASS")
	quit()

func _bounds(node: Node) -> AABB:
	var bounds := AABB()
	var found := false
	for child in node.find_children("*", "MeshInstance3D", true, false):
		var instance := child as MeshInstance3D
		if instance.mesh == null:
			continue
		var box: AABB = instance.get_aabb()
		box = instance.global_transform * box
		if not found:
			bounds = box
			found = true
		else:
			bounds = bounds.merge(box)
	return bounds
```

## The F-117's parts carry no names, so its canopy is found by where it is:
## the mesh spanning the top of the forward fuselage. Same treatment as the
## named path, so the pilot can see out.
static func clarify_canopy_by_bounds(root: Node3D, region: AABB) -> int:
	var changed := 0
	for child in root.find_children("*", "MeshInstance3D", true, false):
		var instance := child as MeshInstance3D
		if instance.mesh == null:
			continue
		var box: AABB = instance.global_transform * instance.get_aabb()
		if not region.encloses(box):

		for surface in range(instance.mesh.get_surface_count()):
			var material := instance.get_active_material(surface)
			if not material is BaseMaterial3D:
				continue
			instance.set_surface_override_material(

			)
			changed += 1
	return changed
